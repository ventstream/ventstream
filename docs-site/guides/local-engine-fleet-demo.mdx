---
title: "Engine + Fleet local demo"
description: "Run a real CDC pipeline under Fleet control on one workstation."
---

This demo starts a Postgres source, an OpenSearch sink, the complete Fleet control
plane, and one real managed engine agent. It verifies that an order reaches
OpenSearch before reporting success.

## Prerequisites

- Docker Desktop with at least 6 GB available memory
- Rust and Cargo
- `curl`, `jq`, `openssl`, and Python 3
- The two repositories cloned next to each other:

```text
workspace/
├── ventstream/
└── ventstream-control-plane/
```

## Run the demo

From the engine repository:

```bash
./demo/fleet/local.sh reset
./demo/fleet/local.sh start
```

The script uses dedicated Compose projects and alternate localhost ports. It does
not reuse or delete the normal VentStream development stacks. It creates a local
built-in account, waits for its Mailpit verification message, verifies the account
through `ventstreamctl`, and only then creates the organization and Fleet
resources.

When `Demo ready` appears, inspect the pipeline and its agent:

```bash
./demo/fleet/local.sh status
```

## Prove CDC

Update an order in Postgres and wait for the managed engine to deliver it to
OpenSearch:

```bash
./demo/fleet/local.sh change
```

The command succeeds only after the updated value is visible in OpenSearch.

## Administer the pipeline

Pause and resume through the Fleet API with `ventstreamctl`:

```bash
./demo/fleet/local.sh pause
./demo/fleet/local.sh resume
```

Run any other CLI command in the demo's authenticated profile:

```bash
./demo/fleet/local.sh ctl pipelines list
./demo/fleet/local.sh ctl agents list --pipeline orders-cdc
```

Follow the managed agent and child-engine logs when troubleshooting:

```bash
./demo/fleet/local.sh logs
```

## Clean up

Stop the processes and containers while retaining the demo state:

```bash
./demo/fleet/local.sh stop
```

Use `reset` before starting a fresh run.

Remove only this demo's containers, volumes, credentials, and generated state:

```bash
./demo/fleet/local.sh reset
```

<Warning>
This workflow uses local development credentials and plaintext HTTP for the
localhost control API. It is not a production deployment template.
</Warning>
